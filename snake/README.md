# 🐍 Realistic Snake Game

A 3D Snake game built with Three.js featuring realistic snake graphics and stunning visual effects.

## ✨ Features

### 🐍 Realistic Snake Graphics
- **Detailed Snake Head**: Features realistic eyes, nostrils, and a forked tongue
- **Body Segments**: Smooth, spherical segments with scale-like textures and highlights
- **Dynamic Head Rotation**: Snake head automatically faces the direction of movement
- **Smooth Movement**: Interpolated movement for fluid, realistic snake motion

### ✨ Visual Effects
- **Glowing Trail**: Dynamic particle system creates a glowing green trail behind the snake
- **Enhanced Lighting**: Multiple light sources including dramatic point lighting
- **Particle Effects**: Food collection creates beautiful particle explosions
- **Smooth Animations**: Floating food and smooth UI transitions

### 🎮 Gameplay
- **Classic Snake Mechanics**: Collect food to grow longer
- **Increasing Difficulty**: Speed increases as the snake grows
- **Collision Detection**: Boundary and self-collision detection
- **Responsive Controls**: Arrow keys and touch/swipe support

### 🎨 Visual Design
- **Modern UI**: Glowing score display with animations
- **Smooth Transitions**: Elegant game over screen with slide-in animation
- **Responsive Design**: Works on desktop and mobile devices
- **Beautiful Background**: Gradient background with atmospheric fog

## 🚀 How to Play

1. **Start the Game**: Press SPACE to begin
2. **Control the Snake**: Use arrow keys to change direction
3. **Collect Food**: Eat the red food spheres to grow longer
4. **Avoid Collisions**: Don't hit the walls or yourself
5. **Grow Longer**: Each food item increases your score and length

## 🛠️ Technical Details

- **3D Graphics**: Built with Three.js for stunning 3D visuals
- **Particle Systems**: Custom trail and collection effects
- **Smooth Interpolation**: Frame-rate independent movement
- **Optimized Rendering**: Efficient 3D scene management
- **Mobile Optimized**: Touch controls and responsive design
